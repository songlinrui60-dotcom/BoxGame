# BoxGame

一个Unity游戏项目。

## 项目结构

```
BoxGame/
├── Packages/          # Unity包管理
├── ProjectSettings/   # 项目设置
├── Assets/            # 游戏资源
└── BoxGame.sln        # Visual Studio解决方案
```

## 开发环境

- Unity 2022.x 或更高版本
- Visual Studio 2022 或 Rider

## 运行方式

1. 使用Unity Hub打开项目
2. 在Unity编辑器中点击Play按钮开始游戏
